## About Mempalace

Mempalace is the highest-scoring AI memory system ever benchmarked. It organizes AI memory into a palace structure (wings, halls, rooms) inspired by the ancient method of loci, achieving 96.6% recall on LongMemEval - higher than any free or paid solution.

Core technology:
- **Palace Structure** - wings, halls, rooms for organized retrieval
- **AAAK Compression** - 30x lossless compression for local models
- **Knowledge Graph** - temporal entity relationships via SQLite
- **MCP Integration** - 19 tools for Claude and MCP-compatible tools
- **100% Local** - no cloud, no API required

Original project: [addyosmani/mempalace](https://github.com/addyosmani/mempalace)
